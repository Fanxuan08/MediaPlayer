# Media Player (客製化多媒體播放器)

## 專案簡介

本專案為一個基於 Windows Media Player 開發的影音播放軟體。
透過隱藏系統預設的控制面板，重新打造了專屬的 UI 介面，並導入了實用的快捷鍵操作邏輯，提供更純粹的觀影體驗。

### 基礎功能

* **多重影音格式支援**
  * 結合 `OpenFileDialog` 並設定專屬的過濾器 (`Filter`)，支援使用者載入 `.wmv`, `.mp4`, `.avi` 等主流影音格式。
* **客製化播放控制**
  * 實作獨立的「播放」、「暫停」、「停止」按鈕，透過呼叫 `wmpVideo.Ctlcontrols` 屬性，精確控制影音串流的執行狀態。

### 進階創意擴充

* **沉浸式 UI 覆寫**
  * 於程式啟動階段強制將 WMP 控制項的 `uiMode` 設為 `"none"`，徹底隱藏內建的進度條與按鈕列，將畫面視覺最大化保留給影音內容本身，也保留創意發想空間給自己的程式 UI 。
* **無縫音量連動控制**
  * 實作 `TrackBar` (滑桿) 控制項。除了在拖曳時 (`Scroll`) 即時更新播放器的音量外，也在表單載入 (`Load`) 時自動進行初始數值同步，確保 UI 顯示與實際音量狀態一致。
* **鍵盤快捷跳轉鍵 (精準跳轉影片進度)**
  * 實作類似 YouTube 的快轉邏輯：使用者可直接透過鍵盤的 **「右方向鍵 (➡️)」** 前進 5 秒，**「左方向鍵 (⬅️)」** 倒退 5 秒。
  * **防呆保護**：內建時間邊界檢查，當倒轉運算可能導致時間小於 0 秒時，程式會自動將進度歸零，避免時間軸發生邏輯錯誤或程式崩潰。


## 執行說明

### 1. 載入影音檔案
點選畫面左下角的「瀏覽」按鈕，系統會開啟檔案選取視窗。選擇欲播放的影片檔後，影片會自動載入播放器中並處於停止預備狀態。

### 2. 畫面與音量控制
* 點擊「播放」開始觀影，過程中可隨時使用「暫停」與「停止」按鈕。
* 拖曳右下角的刻度滑桿，即可無延遲地調節影片音量大小。

### 3. 鍵盤快捷操作
影片播放途中，無需使用滑鼠點擊進度條，直接操作鍵盤方向鍵即可實現快速尋軌：
* 按下 `→`：快轉 5 秒。
* 按下 `←`：倒退 5 秒。
